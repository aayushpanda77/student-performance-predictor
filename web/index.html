How the Linear Regression Model Works

Trained using Scikit-learn's LinearRegression on 800 training records and evaluated on 200 test records, the model computes predictions using the learned equation:

Final Score = 7.3621 + (2.9873 × Study Hours) + (0.2407 × Attendance) + (0.3771 × Assignment) + (1.2546 × Sleep)
  • Intercept (β₀): 7.3621
  • Study Hours Weight (β₁): +2.9873 pts per daily hour
  • Attendance Weight (β₂): +0.2407 pts per percentage point
  • Assignment Weight (β₃): +0.3771 pts per assignment mark
  • Sleep Hours Weight (β₄): +1.2546 pts per sleep hour
